# Team Big Apple · December 2026 FOMC briefing

Interactive briefing for our December 2026 FOMC recommendation: raise the federal funds target range by 25 basis points, to 4.00%–4.25%.

Team: KK Ananth, Shardul Kachare, Stephanie Demo, Grace Alexander, Alvin Wu.

**Live page:** https://wkf-alvin.github.io/FNCE-613-Fed-Challenge-NY/

- One self-contained `index.html` (plain JavaScript and SVG, no build step).
- Charts use official data from FRED (Federal Reserve Bank of St. Louis), retrieved November 24, 2026. Sources and methods are behind the page's Sources link (top right).
- Keys: ← → move between chapters, 0–9 jump to one, F toggles full screen, T switches the theme.

Student project. The 25 bp hike is our proposed position, not official Federal Reserve policy, and this project is not affiliated with the Federal Reserve.
